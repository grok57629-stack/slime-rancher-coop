## 📋 О проекте

**SRMP Revival** — это стабильная и доработанная версия модификации **Slime Rancher MultiPlayer (SRMP)** для игры **Slime Rancher 1**.

### 🌟 Что синхронизировано:
- **Игроки**: отображение 3D-моделей (аватаров), плавные движения, анимации, направление взгляда и маркеры на карте (`M`).
- **Вак-пак и инвентарь**: стрельба, всасывание, перенос предметов, валюта (Newbucks).
- **Слаймы и мир**: физика слаймов, их эмоции, голод, сытость, появление ларго, дикие слаймы (Feral), тарры и гордо.
- **Ранчо и постройки**: загоны (Corrals), сады (Gardens), силосы (Silos), автокормушки, сборщики плортов (Plort Collectors), утилизаторы.
- **Дроны и гаджеты**: работа дронов и установка слаймонаучных устройств.

## ⚡ Быстрая установка (1 клик)

### Вариант 1: Через Графический Лаунчер (Рекомендуется)
1. Откройте файл `launcher/Coop-Manager.cmd` (двойным кликом).
2. Проверьте путь к игре (лаунчер автоматически найдет Slime Rancher в Steam).
3. Введите ваш желаемый **Ник игрока**.
4. Нажмите **`⚡ Установить кооп`**.
5. Нажмите **`🚀 Запустить игру`**.

### Вариант 2: Через консольный скрипт
1. Запустите `launcher/Install-Coop.cmd`.
2. Скрипт сделает бэкап оригинального файла `Assembly-CSharp.dll`, пропатчит загрузчик модов `SRML` и установит `SRMP.dll`.
3. Запустите игру через Steam.

## 🌐 Сетевые режимы и подключение

Мод поддерживает два способа совместной игры:

### Режим 1: Подключение без проброса портов (EOS Server Code) — РЕКОМЕНДУЕТСЯ
*Не требует белого IP, настройки роутера или сторонних программ (Hamachi/Radmin).*

1. **Хост**:
   - Войдите в свой мир в Slime Rancher.
   - Нажмите клавишу **`F4`** для открытия меню мультиплеера.
   - Нажмите **`Host Game`** в блоке EOS.
   - Игра сгенерирует буквенно-цифровой код (**Server Code**).
   - Скопируйте его и отправьте другу.
2. **Клиент (Друг)**:
   - Запустите Slime Rancher.
   - Нажмите **`F4`**.
   - В поле **`Server Code`** вставьте полученный код.
   - Нажмите **`Connect`**. Соединение произойдет автоматически!

### Режим 2: Прямое подключение по IP / LAN / Radmin / Tailscale
*Идеально для локальной сети или выделенного сервера.*

1. **Хост**:
   - Нажмите **`F4`** -> **`Host Game`** (порт по умолчанию: `6996` или `16500`).
2. **Клиент**:
   - Введите локальный IP хоста (или IP из виртуальной сети) и порт.
   - Нажмите **`Connect`**.

## 🎮 Управление и горячие клавиши

| Клавиша / Команда | Действие |
|---|---|
| **`F4`** | Открыть / скрыть меню мультиплеера и список игроков |
| **`Enter`** | Открыть внутриигровой текстовый чат |
| **`M`** | Игровая карта (позиции друзей отображаются метками) |
| **`/home`** | Мгновенная телепортация на базу/ранчо |
| **`/ping`** | Показать текущую задержку (пинг) до хоста |
| **`/tps`** | Показать тикрейт сервера (плавность симуляции) |
| **`/list`** | Список всех игроков онлайн |
| **`/sleep <часы>`** | Пропустить время суток (сон) |

## 🖥️ Выделенный сервер (Dedicated Server 24/7)

Если вы хотите, чтобы мир ранчо работал постоянно для ваших друзей:
1. Запустите скрипт `serveur/run.cmd` (или через кнопку в `Coop-Manager`).
2. Сервер запустится в фоновом режиме без графической оболочки.
3. **Функция AutoHost Pause**: мир автоматически ставится на паузу, когда на сервере 0 игроков — слаймы не погибнут от голода, пока вас нет.

---

## ↩️ Удаление мода (Возврат к оригиналу)

- Запустите `launcher/Uninstall-Coop.cmd` (или нажмите кнопку в `Coop-Manager`).
- Скрипт мгновенно восстановит оригинальный `Assembly-CSharp.dll` и удалит файлы мода. Игра станет 100% чистой ваниллой.
